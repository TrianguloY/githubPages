### Visor:

#### Urls: 

Video: [https://trianguloy.github.io/githubPages/Visor/visor.html](https://trianguloy.github.io/githubPages/Visor/visor.html)

Swf: [https://trianguloy.github.io/githubPages/Visor/ruffleVisor.html](https://trianguloy.github.io/githubPages/Visor/ruffleVisor.html)

#### Description:

- Video: Plays a video from a url directly on the browser (without downloading). \
It uses the video player of the browser, so unfortunately it only appears to work with some files and some browsers (It seems to work with most .mp4 files on firefox and chrome, also with some .mkv on chrome, some audios too, ...). \
{20% cooler version: [https://trianguloy.github.io/githubPages/Visor/YPvisor.html](https://trianguloy.github.io/githubPages/Visor/YPvisor.html) }

- Swf: Plays a swf file from a url directly in the browser, using [Ruffle](https://ruffle.rs/).

You can append the url of the video/swf after a "?" to autoload a predefined url (may also autoplayed if the browser allows it, otherwise you need to press play). For example: 
- [https://trianguloy.github.io/githubPages/Visor/visor.html?https://sample-videos.com/video123/mp4/240/big_buck_bunny_240p_30mb.mp4](https://trianguloy.github.io/githubPages/Visor/visor.html?https://sample-videos.com/video123/mp4/240/big_buck_bunny_240p_30mb.mp4)
- [https://trianguloy.github.io/githubPages/Visor/ruffleVisor.html?https://ruffle.rs/logo-anim.swf](https://trianguloy.github.io/githubPages/Visor/ruffleVisor.html?https://ruffle.rs/logo-anim.swf)
